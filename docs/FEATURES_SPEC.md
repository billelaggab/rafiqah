يوثّق هذا الملف كل الخوارزميات الطبية المعتمدة في التطبيق والمواصفات الوظيفية التفصيلية لكل وضع من الأوضاع الأربعة.

## 1. الخوارزميات الطبية المعتمدة

### 1.1 حساب موعد الولادة المتوقع — Modified Naegele's Rule

| البند | القيمة |
|:---|:---|
| **المرجع العلمي** | قاعدة Naegele (1812) مع تصحيح الطور الإباضي |
| **الصيغة** | `EDD = LMP + 280 يومًا + (طول الدورة − 28)` |
| **سبب التعديل** | القاعدة الأصلية تفترض دورة 28 يومًا للجميع، مما يعطي نتائج مضللة للدورات الأطول/الأقصر |

```dart
/// حاسبة موعد الولادة المتوقع — قاعدة Naegele المعدلة فسيولوجيًا
///
/// تصحح الخطأ الشائع بتعديل يوم التبويض الفعلي
/// بناءً على طول الدورة الحقيقي للمستخدمة.
///
/// [lmp]: تاريخ أول يوم من آخر دورة شهرية
/// [cycleLength]: متوسط طول الدورة الشهرية بالأيام
DateTime calculateEDD({required DateTime lmp, required int cycleLength}) {
  final int adjustment = cycleLength - 28;
  return lmp.add(Duration(days: 280 + adjustment));
}
```

**أمثلة عملية:**

| آخر دورة (LMP) | طول الدورة | التعديل | الموعد المتوقع (EDD) |
|:---|:---:|:---:|:---|
| 1 يناير 2027 | 28 يومًا | 0 | 8 أكتوبر 2027 |
| 1 يناير 2027 | 32 يومًا | +4 | 12 أكتوبر 2027 |
| 1 يناير 2027 | 25 يومًا | −3 | 5 أكتوبر 2027 |

### 1.2 نافذة التبويض والخصوبة — Ovulation & Fertile Window

**الأساس الفسيولوجي:**
- الطور الأصفري (Luteal Phase) ثابت تقريبًا عند **14 يومًا** بغض النظر عن طول الدورة.
- الحيوانات المنوية تعيش حتى **5 أيام** في الجهاز التناسلي الأنثوي.
- البويضة قابلة للإخصاب لمدة **12-24 ساعة** بعد التبويض.

```dart
/// حساب يوم التبويض ونافذة الخصوبة
///
/// [periodStartDate]: أول يوم من الدورة الحالية
/// [cycleLength]: متوسط طول الدورة بالأيام
({DateTime ovulationDay, DateTime fertileStart, DateTime fertileEnd})
calculateFertileWindow({
  required DateTime periodStartDate,
  required int cycleLength,
}) {
  // يوم التبويض = طول الدورة − 14 (ثبات الطور الأصفري)
  final ovulationDay = periodStartDate.add(Duration(days: cycleLength - 14));

  // نافذة الخصوبة = 5 أيام قبل التبويض ← يوم بعد التبويض
  final fertileStart = ovulationDay.subtract(const Duration(days: 5));
  final fertileEnd   = ovulationDay.add(const Duration(days: 1));

  return (
    ovulationDay: ovulationDay,
    fertileStart: fertileStart,
    fertileEnd: fertileEnd,
  );
}
```

**الحرارة القاعدية (BBT):**
- ارتفاع الحرارة بمقدار **0.2-0.5°C** بعد التبويض يؤكد حدوثه.
- يُسجَّل القياس صباحًا **قبل النهوض من السرير** بنفس الميزان يوميًا.

### 1.3 خوارزمية فرز انقباضات الولادة — Rule 5-1-1

> **الهدف:** تنبيه الحامل بالتوجه الفوري للمستشفى عند دخولها مرحلة المخاض النشط.

**الشروط الثلاثة (يجب تحققها جميعًا):**

| # | المعيار | القيمة الحرجة | الشرح الفسيولوجي |
|:---:|:---|:---:|:---|
| **5** | الفاصل بين الانقباضات | **≤ 5 دقائق** | تقلّص الفترات يعني تقدم المخاض |
| **1** | مدة الانقباضة | **≥ 60 ثانية** | انقباضات المخاض الحقيقي أطول من Braxton Hicks |
| **1** | استمرارية النمط | **≥ ساعة كاملة** | استمرار النمط ينفي كونها انقباضات كاذبة |

**السلوك في الواجهة عند تحقق القاعدة:**

```text
┌─────────────────────────────────────────┐
│  🔴 تحذير — توجهي للمستشفى فورًا!      │
│                                         │
│  ✓ الانقباضات كل 4 دقائق               │
│  ✓ كل انقباضة تستمر 65 ثانية           │
│  ✓ النمط مستمر منذ ساعة و12 دقيقة      │
│                                         │
│  [🏥 أقرب مستشفى ولادة]  [📞 اتصلي]     │
└─────────────────────────────────────────┘
```

- تتحول **خلفية الشاشة** إلى اللون الأحمر
- يُصدَر **تنبيه صوتي** واضح
- يظهر زر **توجيه لأقرب مستشفى ولادة** (عبر `GeoRoutingService`)

```dart
/// التحقق من تحقق قاعدة 5-1-1
bool shouldAlertHospital(List<ContractionLog> contractions) {
  if (contractions.length < 3) return false;

  final recent = contractions.sublist(contractions.length - 3);

  // الشرط 1: كل انقباضة ≥ 60 ثانية
  final allLongEnough = recent.every((c) => c.durationSeconds >= 60);

  // الشرط 2: الفاصل بين كل انقباضتين ≤ 5 دقائق
  final allCloseEnough = recent.every((c) => c.intervalSeconds <= 300);

  // الشرط 3: النمط مستمر ≥ ساعة
  final totalSpan = recent.last.endTime.difference(recent.first.startTime);
  final spansOneHour = totalSpan >= const Duration(hours: 1);

  return allLongEnough && allCloseEnough && spansOneHour;
}
```

### 1.4 مقياس إيدنبرة لاكتئاب ما بعد الولادة — EPDS

| البند | القيمة |
|:---|:---|
| **عدد الأسئلة** | 10 أسئلة موحدة |
| **المقياس** | 0-3 لكل سؤال (المجموع 0-30) |
| **حد التنبيه** | نتيجة ≥ 13 = توجيه هادئ لطلب المساعدة المتخصصة |
| **نبرة النتيجة** | داعمة وغير مخيفة — لا تشخيص طبي |

> ⚠️ المقياس **لا يُشخِّص** الاكتئاب. هو أداة فرز أولية تُوجّه الأم بهدوء لاستشارة مختصة إذا لزم الأمر.

## 2. المواصفات حسب الوضع

### 2.1 وضع متابعة الدورة الشهرية — Cycle Tracker

| الميزة | التفاصيل |
|:---|:---|
| **التقويم التفاعلي** | يلوّن مراحل الدورة بألوان مميزة: 🔴 حيض → 🟡 طور جرابي → 🟢 تبويض → 🔵 طور أصفري |
| **التسجيل اليومي** | الأعراض: صداع، تقلبات مزاجية، إفرازات، آلام الظهر، انتفاخ |
| **التنبؤ الذكي** | موعد الدورة القادمة بناءً على متوسط آخر 3-6 دورات مسجلة |
| **فحص الثدي** | تذكير شهري بالفحص الذاتي بعد انتهاء الدورة بـ 3 أيام |
| **تصدير البيانات** | إمكانية تصدير سجل الدورات لمشاركته مع الطبيبة |

### 2.2 وضع التخطيط للحمل — TTC

| الميزة | التفاصيل |
|:---|:---|
| **لوحة الخصوبة** | عد تنازلي لأفضل أيام الإخصاب مع تلوين نافذة الخصوبة |
| **رسم BBT** | رسم بياني تفاعلي لحرارة الجسم القاعدية لتأكيد التبويض |
| **نصائح يومية** | تحفيز نمط حياة صحي (تغذية، حمض الفوليك، تقليل التوتر) |

> 🚫 **سياسة تحديد جنس المولود:** ممنوع قطعيًا تضمين خوارزميات تزعم اختيار جنس المولود بناءً على توقيت الجماع (طريقة شيتلز). تُدرج فقط كمقال نقدي تثقيفي يوضح ضعفها العلمي — لتجنب حظر التطبيق من Google Play.

### 2.3 وضع أنا حامل — Pregnancy

| الميزة | التفاصيل |
|:---|:---|
| **تطور الجنين الأسبوعي** | حجم مقارن بالفواكه، الطول (CRL/BPD)، الوزن، والتغيرات الفسيولوجية |
| **ركن التطمين الجلدي** | كارت توعوي يبدأ من الأسبوع 14: تصبغات الرقبة/الإبط/البطن (Linea Nigra) طبيعية ومؤقتة بسبب هرمون MSH، مع تحذير من كريمات التفتيح (الهيدروكينون) |
| **عدّاد الركلات** | تسجيل دقيق لحركة الجنين — هدف 10 ركلات في ساعتين. تنبيه بالخمول إذا لم يتحقق |
| **مؤقت الانقباضات** | تطبيق خوارزمية 5-1-1 مع تنبيه أحمر وصوتي |
| **دليل الأغذية** | بحث محلي فوري في +200 صنف مع تصنيف: ✅ آمن / ⚠️ بحذر / 🚫 ممنوع |
| **توجيه الطوارئ** | بحث فوري عن: عيادة نساء، مختبر تحاليل، مستشفى ولادة |

### 2.4 وضع أم جديدة — Postpartum & Baby

| الميزة | التفاصيل |
|:---|:---|
| **مؤقت الرضاعة** | تتبع وقت الرضاعة لكل ثدي (يسار/يمين) لضمان التوازن وتحفيز إنتاج الحليب |
| **سياسة Fed is Best** | دعم إيجابي للرضاعة الطبيعية وحليب اللبأ، بدون أي لوم للأم غير القادرة |
| **مقياس EPDS** | 10 أسئلة لفرز اكتئاب ما بعد الولادة مع توجيه هادئ |
| **صحة الأم** | متابعة النزيف (النفاس)، التعافي الجسدي، ألم الجرح (قيصرية/طبيعي) |
| **تتبع الرضيع** | تسجيل: تغذية (ثدي/زجاجة + الكمية)، نوم، حفاضات، تطعيمات |
| **نمو الرضيع** | منحنيات النمو (الوزن/الطول/محيط الرأس) مقارنة بمعايير WHO |

## 3. دليل الأغذية التفاعلي — Food Directory

### 3.1 نظام تصنيف الأمان

| المستوى | الرمز | المعنى | أمثلة |
|:---:|:---:|:---|:---|
| 1 | ✅ | **آمن** — يمكن تناوله بحرية | التفاح، الأرز، الدجاج المطهو جيدًا |
| 2 | ⚠️ | **بحذر** — كمية محدودة أو طريقة تحضير معينة | التونا (بحذر لمحتوى الزئبق)، الكافيين |

### 3.2 الأسباب الطبية للمنع

| السبب | الشرح | أمثلة أغذية ممنوعة |
|:---|:---|:---|
| **ليستيريا** (Listeria) | بكتيريا خطيرة على الجنين توجد في الأطعمة غير المبسترة | أجبان طرية، لحوم باردة |
| **توكسوبلازميا** (Toxoplasmosis) | طفيلي ينتقل عبر اللحوم النيئة وملامسة القطط | لحوم نيئة/نصف مطهوة |
| **زئبق** (Mercury) | معدن ثقيل يضر بالجهاز العصبي للجنين | أسماك كبيرة (سيف، قرش، إسقمري ملكي) |
| **كافيين مفرط** | كميات كبيرة ترتبط بزيادة خطر الإجهاض | > 200mg/يوم (≈ فنجانين قهوة) |
