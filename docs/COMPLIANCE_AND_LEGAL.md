# ⚖️ الامتثال القانوني وسياسات المتجر — Compliance & Privacy

يوثّق هذا الملف كافة متطلبات الامتثال القانوني والطبي وسياسات الخصوصية اللازمة لنشر التطبيق على Google Play Store.

---

## 1. نموذج إعلان التطبيقات الصحية — Google Play Health Declaration

عند نشر التطبيق على **Google Play Console**، يجب الإجابة على نموذج التصريح الصحي كما يلي:

| السؤال | الإجابة المعتمدة |
|:---|:---|
| **تصنيف التطبيق** | **Health & Fitness App** (تطبيق صحة ولياقة — وليس جهازًا طبيًا Medical Device) |
| **هل يقدم تشخيصًا طبيًا؟** | **لا** — أدوات تثقيفية وإرشادية فقط |
| **هل يشارك بيانات صحية مع أطراف ثالثة؟** | **لا** — جميع البيانات تُحفظ محليًا على الجهاز |
| **هل يخزن بيانات صحية على خوادم خارجية؟** | **لا** — التخزين محلي حصريًا (Drift/SQLite) |
| **هل يوفر نسخًا احتياطيًا سحابيًا؟** | **نعم** — على Google Drive في مجلد التطبيق المخفي (`drive.appdata`)، مُشفَّر بـ AES-256 محليًا قبل الرفع |

## 2. الإقرار الطبي الإلزامي — Mandatory In-App Disclaimer

### 2.1 شروط العرض

| الشرط | التفاصيل |
|:---|:---|
| **التوقيت** | يظهر عند **أول فتح** للتطبيق بعد التثبيت |
| **إمكانية التخطي** | **لا يمكن تخطيها** — النافذة غير قابلة للإلغاء (non-dismissible) |
| **حفظ الموافقة** | تُخزَّن محليًا في `UserProfiles` — لا تظهر مجددًا بعد الموافقة |
| **التصميم** | `AlertDialog` بخلفية بيضاء، نص واضح بحجم مقروء، زر واحد فقط |

## 3. معايير سياسة الخصوصية — Privacy Policy

### 3.1 التوافق مع الأطر القانونية الدولية

| الإطار | حالة التوافق | الآلية |
|:---|:---:|:---|
| **GDPR** (أوروبا) | ✅ | لا خوادم وسيطة — بيانات محلية فقط — حق المحو متاح |
| **HIPAA** (أمريكا) | ✅ هيكليًا | لا نقل بيانات صحية عبر الشبكة بدون تشفير مسبق |
| **سياسات Google Play** | ✅ | إقرار طبي إلزامي + تصنيف Health & Fitness |

### 3.2 حقوق المستخدمة

| الحق | التنفيذ في التطبيق |
|:---|:---|
| **الاطلاع** | جميع البيانات مرئية داخل التطبيق — لا بيانات مخفية |
| **التصدير** | إمكانية تصدير سجلات الدورة والحمل لمشاركتها مع الطبيبة |
| **المحو الكامل** | زر **"مسح جميع بياناتي"** في الإعدادات — يحذف كل شيء بنقرة واحدة |
| **رفض النسخ الاحتياطي** | النسخ الاحتياطي **اختياري** تمامًا — التطبيق يعمل بدونه |

### 3.3 زر المحو الكامل — Right to be Forgotten

```dart
// features/settings/presentation/providers/data_deletion_notifier.dart

Future<void> deleteAllUserData() async {
  // 1. حذف جميع السجلات من كل الجداول
  await _database.delete(_database.menstrualLogs).go();
  await _database.delete(_database.kickSessions).go();
  await _database.delete(_database.contractionLogs).go();
  await _database.delete(_database.babyCareLogs).go();

  // 2. إعادة تعيين الملف الشخصي
  await _database.delete(_database.userProfiles).go();

  // 3. حذف النسخة الاحتياطية من Google Drive (إن وُجدت)
  await _backupService.deleteRemoteBackup();

  // 4. حذف المفتاح المحلي من Secure Storage
  await _secureStorage.deleteAll();

  // 5. إعادة تهيئة التطبيق
  ref.invalidate(databaseProvider);
}
```

## 4. البيانات المُجمَّعة والإعلانات

### 4.1 ما يُجمَع عبر AdMob

| البيان | الغرض | تحكم المستخدمة |
|:---|:---|:---|
| **معرّف الإعلان** | تخصيص الإعلانات | يمكن تعطيله من إعدادات Android |
| **بيانات الجهاز العامة** | توافق الإعلان | لا يشمل بيانات صحية |

### 4.2 ما لا يُجمَع أبدًا

| البيان | السبب |
|:---|:---|
| ❌ سجلات الدورة الشهرية | بيانات صحية حساسة — محلية فقط |
| ❌ تاريخ الحمل أو الولادة | بيانات صحية حساسة — محلية فقط |
| ❌ نتائج EPDS | بيانات صحة نفسية — محلية فقط |
| ❌ سجلات الرضاعة والطفل | بيانات صحية حساسة — محلية فقط |
| ❌ الموقع الجغرافي | لا يُخزَّن — يُستخدم لحظيًا فقط عبر تطبيق الخرائط |

## 5. قائمة التحقق القانونية قبل النشر

- [ ] صفحة سياسة الخصوصية منشورة على رابط عام ومُضافة في Google Play Console
- [ ] نموذج التصريح الصحي مُعبأ بالقيم الصحيحة في Play Console
- [ ] الإقرار الطبي يظهر إلزاميًا عند أول فتح ولا يمكن تخطيه
- [ ] زر "مسح جميع بياناتي" يعمل بشكل كامل ويحذف كل شيء
- [ ] لا يوجد أي إرسال لبيانات صحية عبر الشبكة بدون تشفير
- [ ] التطبيق يعمل بالكامل بدون تسجيل دخول Google (Drive اختياري)
- [ ] معلومات التواصل للمطور مُضافة في Play Console وسياسة الخصوصية
